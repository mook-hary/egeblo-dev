# CUBE dev

ブラウザで遊べる **3Dマッチングパズルゲーム** です。  
同じ柄のブロックをペアで選んで消し、制限時間内にすべて消すとクリアです。

**公開URL（GitHub Pages）:** https://mook-hary.github.io/egeblo-dev/

---

## 1. ゲーム概要

- **ジャンル:** 3D マッチングパズル
- **技術:** HTML / CSS / JavaScript（フレームワークなし）
- **見た目:** WebGL ではなく、CSS の 3D 変換（`perspective` / `preserve-3d`）で立方体を表示
- **目的:** 立方体に並んだブロックを、同じ柄のペアで消していき、すべて消去する

スコア・ベスト記録・難易度の選択などは、ブラウザの **localStorage** に保存されます。

---

## 2. 遊び方

1. タイトル画面で **LEVEL**（Normal / Hard など）を選び、**START** を押す  
   - 初めての方は **Tutorial** から始めるのがおすすめです
2. **1つ目のブロック** をクリックして選択する
3. **同じ柄のブロック** をもう1つ選ぶと、2つが消えて **+700 pt**
4. 同じブロックをもう一度選ぶと、選択を解除できる
5. 柄が違うブロックを選ぶと、「数字が違います」と表示され、2つ目として選び直す

### 選べるブロックの条件

**左右・前後の4方向のうち、2方向以上が空いているブロック** だけ選べます。  
周囲に挟まれているブロックは選べません。

### その他の操作

| ボタン | 作用 |
|--------|------|
| ⇨ / ⇩ | パズル全体の向きを回転（ブロックの位置を入れ替え） |
| PAUSE | 一時停止 |
| RESET | 同じ条件でもう一度プレイ |
| 🔊 | サウンド ON / OFF |

### クリアとスコア

- **制限時間:** 120 秒（Tutorial は無制限）
- **クリア時:** マッチ得点に加え、**クリアボーナス** と **タイムボーナス**（残り秒 × 2,000 pt）が加算される
- 時間切れになると **TIME UP** となる

## 3. 難易度

| モード | 立方体サイズ | 備考 |
|--------|-------------|------|
| **Tutorial** | 2 × 2 × 2 | スコア・タイマーなし。操作の練習用 |
| **Normal** | 4 × 4 × 4 | デフォルト難易度 |
| **Hard** | 6 × 6 × 6 | 初クリアで **Extra** モードが解放される |
| **Extra** | 8 × 8 × 8 | Hard をクリアしたあとに選択可能 |

## 4. ファイル構成

```
egeblo-dev/
├── index.html      # 画面の HTML（タイトル・ゲーム画面・各種オーバーレイ）
├── script.js       # ゲームロジック・音声・UI 制御（約 2,600 行）
├── style.css       # レイアウト・3D 表示・UI のスタイル
├── assets/
│   └── ogp.png     # SNS 共有用の画像（OGP）
├── sounds/         # BGM・効果音（mp3）
└── README.md       # このファイル
```

| ファイル | 主な役割 |
|----------|----------|
| `index.html` | タイトル / 一時停止 / クリア / Extra 解放などの画面構造 |
| `script.js` | ブロック生成・選択判定・スコア・タイマー・音声・localStorage |
| `style.css` | 16:9 レイアウト、3D ステージ、ボタン・オーバーレイの見た目 |
| `sounds/` | BGM 3曲、選択・消去・エラー・ファンファーレなど |

## 5. localStorage で保存している情報

ブラウザごとに、次の4種類のデータが保存されます。

| キー | 内容 | 例 |
|------|------|-----|
| `cube_difficulty` | 選択した難易度（立方体のサイズ） | `4`（Normal） |
| `cube_extra_unlocked` | Extra モードの解放状態 | `"true"` |
| `cube_sound_enabled` | サウンド ON / OFF | 未設定または `"true"` で ON、`"false"` で OFF |
| `egebro_highscore_sz{SIZE}` | 難易度別のベストスコア | `egebro_highscore_sz4` など |

**保存されないもの:** プレイ中の盤面、残り時間、一時停止状態など（ページを閉じるとリセットされます）。

## 7. 開発メモ

### ローカルで動かす

プロジェクトのフォルダで、簡易 HTTP サーバーを起動して確認するのがおすすめです。

```bash
# Python 3 の例
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。  
（`index.html` を直接ダブルクリックで開く方法でも動きますが、音声読み込みなどで制限が出る場合があります。）

### コードの特徴

- ゲームの処理はほぼ **`script.js` 1ファイル** に集約されています
- 3D 表示は CSS 3D Transform。カメラ回転ではなく、**回転ボタンでブロック座標を入れ替える** 方式です
- モバイル縦持ち時は CSS で画面を 90 度回転し、横画面レイアウトで表示します

### 開発用 UI

ゲーム画面右上に **✅（クリアテスト）** ボタンがあります。  
開発・デバッグ用で、押すと即クリア処理が走ります。本番公開時は非表示にするなどの検討余地があります。

### 音声

- 効果音: Web Audio API
- BGM: HTMLAudioElement（3 曲からランダム再生）
- タブを非表示にすると BGM が一時停止します

### 今後の改善候補（参考）

- `script.js` の機能別分割
- 未使用コード・開発用ボタンの整理
- localStorage キー名の統一（`egebro` → `egeblo` など、既存データ移行が必要）
- 盤面の途中保存、ドラッグでの視点操作 など
